# 🐍 Python no Bolso

Aplicativo educacional para aprender e praticar os primeiros conceitos de Python diretamente pelo celular.

## 🌐 Acessar na Web

O **Python no Bolso** também pode ser acessado diretamente pelo navegador, sem precisar instalar nada:

👉 https://python-no-bolso.pages.dev

A versão web funciona em computadores, Android e iPhone/iPad.

## 🍎 Instalar no iPhone ou iPad

No iOS/iPadOS, o Python no Bolso pode ser instalado como um **Web App** pela tela inicial:

1. Abra o **Safari**.
2. Acesse https://python-no-bolso.pages.dev.
3. Toque no botão **Compartilhar**.
4. Selecione **Adicionar à Tela de Início**.
5. Ative **Abrir como App da Web**, se essa opção aparecer.
6. Toque em **Adicionar**.
7. Abra o **Python no Bolso** pelo novo ícone criado na Tela de Início.

Ao abrir pelo ícone, o aplicativo funciona em modo standalone, com uma experiência semelhante à de um app instalado.

## 📲 Instalação no Android

1. Baixe o APK pelo botão acima.
2. Abra o arquivo no dispositivo Android.
3. Se solicitado, permita a instalação de aplicativos dessa fonte.
4. Instale e abra o **Python no Bolso**.

Como alternativa, também é possível acessar a versão web diretamente pelo navegador.

## 🎓 Sobre o projeto

O Python no Bolso foi desenvolvido como projeto educacional de extensão curricular, com o objetivo de tornar os primeiros passos na programação mais simples e acessíveis.
