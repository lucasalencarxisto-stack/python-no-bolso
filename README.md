# 🐍 Python no Bolso

Aplicativo educacional para aprender e praticar os primeiros conceitos de Python diretamente pelo celular.

## ✨ Recursos

- 📚 Trilha com 6 aulas introdutórias de Python
- 🔓 Progressão sequencial das aulas
- 🐍 Execução real de Python com Pyodide
- 💻 Laboratório livre para testar códigos
- ✅ Desafios práticos
- 🧠 Quiz de conhecimentos
- 💾 Progresso salvo no dispositivo
- 📖 Recursos para continuar aprendendo

## 📲 Instalação

1. Baixe o APK pelo botão acima.
2. Abra o arquivo no dispositivo Android.
3. Se solicitado, permita a instalação de aplicativos dessa fonte.
4. Instale e abra o **Python no Bolso**.

## 🎓 Sobre o projeto

O Python no Bolso foi desenvolvido como projeto educacional de extensão curricular, com o objetivo de tornar os primeiros passos na programação mais simples e acessíveis.
